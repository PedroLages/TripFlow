
# 🚀 TripFlow: AI-Powered Tactical Trip Planner

**TripFlow** is a high-fidelity trip planning application designed for explorers who demand precision and aesthetics. Built with a "Thumb-First" mobile strategy and deep Google Gemini API integration, it transforms fragmented travel logistics into a unified, actionable mission dashboard.

## ✨ Key Features

- **AI Vision Receipt Scanning**: Capture physical receipts using your camera; TripFlow uses Gemini to extract amounts, categories, and vendors directly into your budget ledger.
- **Smart Itinerary Generation**: Create multi-day plans with tactical waypoint tracing and automated activity suggestions based on your destination.
- **Live Intel & Alerts**: Get real-time weather and operational status updates for your target sectors.
- **Financial Command Center**: Track multi-currency expenses with live exchange rates and visual allocation matrices.
- **Gear Loadout Management**: AI-suggested packing lists tailored to your destination's climate and trip duration.
- **Secure Document Vault**: Store flight, hotel, and car rental credentials with live status tracking.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS (Custom "Operational" UI Kit)
- **Intelligence**: Google Gemini API (@google/genai)
- **Navigation**: React Router 7
- **Visualization**: Recharts (Custom Data HUDs)
- **Mapping**: Leaflet.js with Tactical Dark Mode tiles
- **Utilities**: date-fns, uuid, Lucide React icons

## 🚦 Getting Started

### Prerequisites
- A Google Gemini API Key (set as `process.env.API_KEY`).

### Execution
1. Open the project in your browser environment.
2. The application will initialize with a demo dataset.
3. Access the **Command Menu** on the left to start a new expedition.

## 📱 Mobile Experience
TripFlow is optimized for on-the-go usage. Core navigation is consolidated into the **Bottom Tactical Bar**, ensuring high-frequency tools are always within thumb's reach while navigating new cities.
